# Word Counter

A React application for character and word counting. The homepage shows the counting tool, and any other URL displays a "Page Not Found" message.

## Links

- **Live site:** https://d-word-counter-app.netlify.app/
- **GitHub repository:** https://github.com/deepikayadav610/word_counter_app

## Features

- Live character and word count as you type
- Clear button to reset the text
- "Page Not Found" page for every route except the homepage
- Responsive design with automatic dark mode

## Tech Stack

- React (Vite)
- React Router
- CSS

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
